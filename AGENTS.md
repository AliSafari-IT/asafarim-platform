# Repository guidance

This is the public, open-source ASafariM implementation repository.

- Keep source code, schemas, tests, public API references, and the minimum
  technical documentation required to build and use the software here.
- Do not add private customer research, pricing hypotheses, commercial
  strategy, internal venture plans, interview notes, or confidential
  roadmaps to this repository.
- Never add credentials, raw customer traces, personal data, or
  contract-confidential prompts.
